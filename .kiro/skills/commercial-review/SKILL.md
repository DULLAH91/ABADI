# Commercial Review

For every candidate technology, produce a concise decision record:

- Purpose
- License
- Commercial-use status
- Redistribution/attribution obligations
- Model/data restrictions
- Security concerns
- Maintenance/activity
- Vendor lock-in
- Cost
- Replacement options
- Strategic value
- Decision: adopt / pilot / reject / investigate

Do not infer licensing from popularity or from a repository name. Verify the actual license and relevant model/data terms before commercial adoption.

Prefer technologies that improve product economics, reliability, differentiation, or deployment flexibility.
